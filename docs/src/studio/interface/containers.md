# Containers

Agents run tools from inside Exegol containers. MCPs can also run from inside a container if you set them up to do so.

Studio discovers containers created by the Exegol [wrapper](/wrapper/). Link one when you create a [project](/studio/interface/projects), or change it later in Settings.

Studio attaches to containers. Creating, starting, stopping, desktop, VPN, and network options may be managed by Studio or the [wrapper CLI](/wrapper/).

## Terminals

Open an interactive shell in the project's container from Studio or from the **bottom panel** terminal. Same filesystem and tunnel as the agent.
